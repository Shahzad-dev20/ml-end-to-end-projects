# US Employee Payroll Prediction Project

## Project Overview
This project builds a machine learning solution to predict employee payroll-related outcomes using structured workforce data. The workflow includes data exploration, preprocessing, model training, and model export for future use.

## Problem Statement
Payroll data often contains patterns that can be analyzed to understand compensation trends, employee categories, and prediction tasks relevant to workforce planning. This project demonstrates how machine learning can be applied to organized employee payroll information.

## Business Value
- Supports workforce analytics and planning
- Helps uncover patterns in employee compensation data
- Demonstrates a complete predictive modeling workflow
- Provides a reusable model artifact for future inference

## Project Workflow
1. Data exploration and analysis
2. Data cleaning and preprocessing
3. Model training and evaluation
4. Model export for deployment use

## Dataset
The project uses a US employee payroll dataset containing payroll-related features and target information.

Download the dataset here:
https://drive.google.com/drive/folders/1XK0PbPhY8r163wGUVtXHvkea6FaJJ058?usp=drive_link

## Model Summary
The final model is a trained predictive model saved as a pickle artifact for inference.

## Project Structure
- notebooks/Employee_Payroll_ML_Notebook.ipynb — end-to-end ML notebook
- models/employee_payroll_best_model.pkl — trained model artifact

## Tech Stack
- Python
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
- Jupyter Notebook

## How to Use
1. Install dependencies from requirements.txt
2. Download and place the dataset in the project folder
3. Open the notebook in notebooks/
4. Load the saved model from models/employee_payroll_best_model.pkl for prediction
