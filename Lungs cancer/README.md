# Lung Cancer Classification Project

## Project Overview
This project focuses on building a machine learning model to classify whether a person is likely to have lung cancer based on medical survey data. The solution uses a supervised classification approach and includes a trained model artifact for future inference.

## Problem Statement
Early detection of lung cancer is critical for improving treatment outcomes. This project aims to build a predictive system that can help identify high-risk individuals from structured survey-style input data.

## Business Value
- Supports early screening efforts
- Helps identify potential high-risk patients
- Demonstrates a practical classification workflow in healthcare analytics
- Provides a reusable model artifact for future deployment

## Project Workflow
1. Data exploration and analysis
2. Preprocessing and feature preparation
3. Model training and evaluation
4. Model selection and export

## Dataset
The project uses a lung cancer dataset containing survey-based medical features and corresponding class labels.

Download the dataset here:
https://drive.google.com/drive/folders/1BLY4iIl9Tzgw8NYz6F-8MQe7SBDnZkAR?usp=drive_link

## Model Summary
The final model is a trained classification model saved as a pickle artifact for inference.

## Project Structure
- notebooks/Lung_Cancer_Classification_Notebook.ipynb — end-to-end classification notebook
- models/lung_cancer_best_model.pkl — trained model artifact

## Tech Stack
- Python
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
- Jupyter Notebook

## How to Use
1. Install dependencies from requirements.txt
2. Download and place the dataset in the project folder
3. Open the notebook in notebooks/
4. Load the saved model from models/lung_cancer_best_model.pkl for prediction
