# U.S. Chronic Disease Indicators Project

## Project Overview
This project focuses on analyzing and modeling U.S. chronic disease indicator data. It explores public health trends, identifies patterns across indicators, and demonstrates an end-to-end data science workflow using a structured dataset.

## Problem Statement
Chronic diseases are a major public health concern in the United States. This project aims to analyze disease prevalence data and provide insights that can support public health monitoring and decision-making.

## Business Value
- Supports public health analysis
- Helps understand disease prevalence patterns across indicators and regions
- Demonstrates data analysis and machine learning workflows on health data
- Provides a reusable notebook-based project structure

## Project Workflow
1. Data loading and exploratory analysis
2. Data cleaning and preparation
3. Analysis of disease indicators and trends
4. Modeling and insight generation

## Dataset
The project uses U.S. Chronic Disease Indicators data from a public health source.

Download the dataset here:
